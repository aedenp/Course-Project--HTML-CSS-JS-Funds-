🃏 Arduino Blackjack Game

A fully functional Blackjack game built on an Arduino Uno with an LCD display, push buttons, and LEDs. Simulated in Tinkercad.

Tech: C++ (Arduino), Electronics, Tinkercad Simulation

View on Tinkercad →

🔍 More about this project:A basic game of blackjack that I have coded as my final project for my Arduino class. I designed this device to simulate a real life style game of blackjack, with functional bank system with betting , hit/stand system, split/double down function, and more all appearing on a 2x16 lcd with custom card/symbol designs.
